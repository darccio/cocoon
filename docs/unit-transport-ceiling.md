# Private successful-unit transport ceiling

Status: specification before implementation, 2026-10-13. Entry is signed
`47f3079`, after the fast interval construction/lookup economic no-go. The
operator authorized one structural boundary-cost question with a measured
ceiling before another implementation. Guest, host and adversarial entry
reviews selected the joint successful-unit transport of `Sketch.Add`.
Review and sign this private specification with exact staged validation before
authoring diagnostic code. This adds no supported public contract.

## One question

Does omitting successful unit publication and validation expose a useful
complete scalar gain while retaining the remaining checked-call envelope?
The earlier existing-ABI `ResultUnit` specialization retained publication and
all wire checks: its isolated component improved, its complete scalar did not,
and SQL regressed. Callback fusion also failed. Neither measured this joint
guest/host omission. Numeric caches, load/store guards, layout tuning, PGO,
typed scalar results and handle pre-resolution are outside this round.

Use only Cocoon's public synthetic Datadog fixture. Production sources,
generated modules, Wasm, manifests, dependencies and all three fixture locks
remain unchanged. The authored AST cause and its generated diagnostic output
travel together in the evidence archive. No private SDK or upstream injector
changes, native arm64 claim, new guest export, ABI version, supported runtime
method or generator option is authorized.

An additional private runtime overlay helper, used only by the additional
private Datadog consumer helper, makes exactly one observable current reply

range (including empty pointers), status dispatch and empty-payload checks on
that path. Inspect the frozen machine code and query-count tests: that query
must not disappear. A non-OK status invokes original `ResultView` exactly once,
without an earlier extra query or a second guest execution, then retains the
original error and unit-shape semantics. Disabled invokes original ResultView

once-only release, home replacement, old-handle nonmigration and terminal
drain. No admission batching, session semantics or re-entry change occurs.

This enabled counterfactual is **unsupported under ABI 3**. It intentionally
accepts some malformed successful replies that ABI 3 must reject, and leaves
old nonempty/error output metadata uncleared. The tests must demonstrate this
divergence and the subsequent state transitions; they must not weaken ABI 3
oracles and claim equivalent wire safety. Original Wasm is a state/bin/Count/
protobuf oracle for this finite experiment, not an oracle for the omitted wire
effects. Keeping one reply query makes this the ceiling of this exact envelope,
not a mathematical maximum or a prediction for all direct-result ABIs.

## Controls and functional proof

source-untouched original Add, checked scaffold and enabled oracle. Checked
and oracle share the same helper/guest entry and a dynamic mode loaded inside
each call; verify the real branch and actual timed calls. Original Add remains
the original direct call, without a function-value adapter replacing it.
Record all scaffold penalties. Original Add in the augmented ELF is source
untouched; adding diagnostics changes linkage, so it is not an untouched ELF.

Also build a separate bare production ELF with the same original harness and
only actual-GOMAXPROCS observation added outside its timer, plus an equivalent
original-only fixed-prefix harness. Preregister the
bare-versus-augmented original scalar and unchanged SQL/batch/trace/streaming
bracket. Preserve any linkage regression; do not move files, pad structures,
inline alternative shapes or retime a selected placement after results.

Before timing, run actual native amd64 and 386 functional proofs. Compare all
three scalar roles for every input of the complete fixed N replays, final
Count and full protobuf; record exact hashes/results. Separately compare
original Wasm versus all roles over bounded ordered histories: growth,
collapse/revisits, threshold/extreme/negative-bin values, valid/error/valid,
nonempty output then enabled OK, stale/fresh handles and independent resources.
Full-N checks are finite Go consistency; bounded Wasm comparisons are not
full-N Wasm proof or universal guest equivalence. Bound this Wasm driver to
2,048 actual operation-export calls per architecture and record its ledger;
count each constructor/method/destructor separately. Record initialization and
reserve/base ABI calls separately, without relabelling a history as one call.

## Decision, stopping and retention

Advance only if complete original adaptive scalar AND fixed Increasing reduce
median time by at least 10%, with exploratory unadjusted p<.05, against ALL
three controls (bare original, augmented source-untouched original and same-ELF
checked scaffold) in BOTH sets. A gain
only against a slower scaffold, one-set gain, smaller gain or failed proof is
NO-GO. For every nonprimary workload in the frozen matrix, including all listed
scalar corpora, holdouts and bare/augmented original workload brackets, reject
any slowdown detected at p<.05 against the same comparator in both sets.
No minor-loss waiver is added after results. Report undetected,
smaller and one-set losses too; nondetection is not equality. All comparisons
are exploratory with multiple-testing limitations.

A positive permits only a separate compatibility/feasibility proposal. Any
new supported payload-free-success or typed-return ABI, schema/version,
mixed-version/migration contract or runtime/generator API requires explicit
operator approval BEFORE implementation. Its required checks must be restored
or proved unnecessary under that approved representation, then its complete
performance qualified independently. If negative, park this question without
unit-helper, fusion, flag, cache or layout retuning in this round.

Report the oracle's remaining gap to M1's original absolute 55.44 ns scalar and
2.2154 µs SQL limits and fresh independent-reference+10% limits. The thresholds
above only determine whether a separate proposal is worthwhile. Neither a
positive unsupported ceiling nor passing unchanged quality gates accepts M1.

Retain durable source/cause/proof/mutant/query/assembly/review/raw/statistical
evidence and limitations in docs/performance.md and a safe hashed archive.
Run all seven gates (`check`, `race`, `rust`, `cross`, `smoke`, `fuzz`,
`integration`) and reproduce all three proof packages/locks plus generated
